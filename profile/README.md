# Project Overview

Everything is a fast desktop search utility for Windows designed to locate files and folders by name with minimal delay.

It provides instant-style filename searching, filtering, sorting, advanced search syntax, bookmarks, and customizable indexing workflows for quickly navigating large collections of files.

---

# Features

- Fast file and folder search
- Real-time search results
- Filename indexing
- Advanced search syntax
- Search filters
- Wildcard searches
- Regular expression support
- Result sorting
- Search history
- Search bookmarks
- Customizable columns
- File operations
- Context menu integration
- Keyboard shortcuts
- Exportable search results
- Lightweight interface

Available functionality can vary depending on Everything version and system configuration.

# Fast File Search

Everything is primarily designed to locate files and folders by their names.

Common searches include:

- Documents
- Applications
- Project files
- Downloads
- Images
- Videos
- Archives
- Executables
- Configuration files
- Entire folders

Results can update dynamically as the search query changes.

---

# Filters & Advanced Search

Search queries can be refined using filters and advanced matching options.

Typical workflows include:

- File extension filtering
- Folder searches
- Wildcards
- Regular expressions
- Date conditions
- Size conditions
- Path matching
- Excluding results
- Combining search terms

These capabilities are useful when working with large drives and extensive directory structures.

---

# Indexing

Everything maintains an index that allows filenames and directory names to be located quickly.

The application is focused primarily on finding files and folders rather than functioning as a full document-content indexing platform.

Indexing behavior and available options depend on the storage configuration and application settings.

---

# File Management

Search results can also be used as an entry point for common file operations.

Users can:

- Open files
- Open folders
- Copy paths
- Rename items
- View properties
- Sort results
- Launch applications
- Access context menus
- Navigate to file locations

Care should be taken when modifying or deleting system files discovered through search.

# Performance

Everything is designed to provide highly responsive filename searches while maintaining a relatively lightweight desktop footprint.

Performance can depend on the number of indexed objects, storage configuration, filters, network resources, and background indexing activity.

---

# Troubleshooting

If expected files do not appear, review indexing settings, excluded locations, filters, permissions, drive availability, and the current search query.

For indexing problems, verify that the relevant volumes and folders are accessible and correctly configured.

Avoid changing unfamiliar system files simply because they appear in search results.
